========================================================================
 仁王 3 装备词条修改器 —— 使用说明（给使用者看）
========================================================================

 仅供测试学习用，不要用于联机影响游戏平衡。
 请先备份存档再使用；本程序只写你指定的副本，绝不改原档。

 开发者请看 README.md / README.zh-CN.md；本文件只讲怎么用。
------------------------------------------------------------------------


一、这是什么
------------------------------------------------------------------------
一个单文件 Windows 程序，用来查看和修改存档里的饰品、魂核与武器 / 防具：

  * 饰品页签：看/改饰品记录的词条、等级、+値、品质、种类、恩宠/套装
  * 魂核页签：看/改魂核记录的词条、等级、+値、品质
  * 武器页签：看/改武器记录的词条、等级、+値、品质、恩宠/套装
    （近战武器与远程武器各用自己的词条表）
  * 防具页签：看/改防具记录的词条、等级、+値、品质、恩宠/套装
    （头部 / 身体 / 手臂 / 腿部 / 足部）
  * 每个词条槽都能下拉选择或直接搜索词条（空格分隔多个关键词 = 同时满足）
  * 程序会拦下不合法的改法（详见第五节的合法规则）

运行要求：Windows 10/11 64 位。首次运行会在自己所在目录旁解压出数据文件
（词条表、图标、加解密组件），属于正常现象；只删除 exe 不会删掉这些文件，
要清干净请把整个文件夹一起删掉。


二、第一次打开：按这个顺序操作
------------------------------------------------------------------------
 1) 关掉游戏。游戏在运行时程序会拒绝写入，这是故意的。

 2) 备份原存档。
    存档一般在：  文档\KoeiTecmo\NIOH3\Savedata\<你的账号ID>\SAVEDATA00\
    里面有 SAVEDATA.BIN 等文件。把整个 SAVEDATA00 文件夹复制一份留底。

 3) 双击 Nioh3EquipmentAffixEditor.exe 打开界面（没有命令行黑框）。

 4) 在【存档】下拉里选中要改的存档（程序会自动列出你机器上的存档：里面就有
    SAVEDATA.BIN；列表不对或空的就先点【刷新】）。
    选中后程序会显示它的路径与大小；界面下方那一行会告诉你当前用的是哪个文件。

 5) 点【读取数据】。
    读完后左侧出现记录列表，右侧是选中记录的词条槽；状态栏会显示记录条数。
    读不出来（提示找不到记录表）说明存档结构没被识别，先别改，把情况反馈过来。

 6) 在左侧列表里点一条记录。右侧 7 个词条槽会填上当前内容：
      槽位下拉框   这个词条是什么（可下拉选择/打字搜索）
      数值输入框   这个词条的数值（固定取值的词条会置灰，不能填）
      槽位说明行   显示存档里的原值、标识、以及为什么不能改（如固定词条、恩宠槽）

 7) 要改哪一项就改哪一项：
      * 换词条：在对应槽的下拉框里选一个新词条；也可以在框里输入关键词搜索，
        回车或选中等候列表刷新；清空输入会恢复该槽的完整词条表。
      * 改数值：在数值框里填数字（有范围的词条会提示范围）。
      * 改等级 / +値：用界面上的等级、+値输入框（等级上限 180，+値上限 30）。
      * 改稀有度（品质）：用【稀有度】输入框（上限按大类：武器 / 防具 / 饰品 4、
        魂核 3，见第八节）。
      * 换恩宠/套装：**就在它的词条槽里选**——那一槽的下拉列出的全是恩宠
        （恩宠 + 上位恩宠）；套装槽会置灰并写明「套装不可替换」。
      * 固定词条（含存档里标了「固定」的）一律不能改，槽位会置灰。
      * 空槽位在当前周目（三周目）不能修改，槽位会置灰。
      * **改完不用一个个确认：点一次【应用修改】，它会把你改过的项一起算出来**，
        一次确认、一次应用（词条 / 等级 / +値 / 稀有度 / 恩宠都算）。
      * 需要新记录时用【新建到空槽】按钮（实验性），按你选的同类物品造一条新记录：
  它在本页**最下方一个独立的框**里（与上面的编辑区分开，避免误触）；武器 / 防具的框里
  还能填**稀有度**（留空 = 沿用模板的稀有度）。

 8) 检查右侧的预览列表：它列出本次将要写入的每一条改动（记录号、槽位、旧→新）。
    不想写这一条就在左侧取消勾选这一条改动。

 9) 点【应用修改】。
    程序会把改动写进内存并逐条校验；有不合法的改法会当场拒绝并说明原因（例如同一
    个物品里出现了两个同种类的词条）。

10) **写入前先确认底部那个【仅演练（不写入）】没有被勾选** —— 勾着它写入不会生效；
    要真正生效，请先取消勾选。确认后点【写入存档】，把结果保存成新文件（也就是写入副本）。
    程序只写你指定的副本路径（默认写到一个单独的测试目录），不会覆盖你选中的原档。

11) 进游戏读取那个副本（放在存档目录里），确认改动生效、图标与文字都对得上。

  武器与防具是另外两个页签，操作完全同构：切到【武器】/【防具】页签即可，
  详见第七节。

  底部那条【应用修改】按**当前页签**生效：在【武器】/【防具】页签里点它，应用的就是
  这一页里你选中的那条装备的改动（不会去动饰品页签的选中项）；【武器】/【防具】页签在
  【预览改动】旁边也有一个【应用修改】，两个按钮作用相同。


三、筛选与查找
------------------------------------------------------------------------
  * 顶部筛选行：按【种类】【恩宠/套装】筛记录；两个筛选会互相收敛——只列出另一个
    筛选仍然允许的选项；当前选择若已无记录，会显示成「xxx（当前无记录）」而不是被
    悄悄清掉，避免你以为筛选没生效。
  * 武器 / 防具页签的筛选行有四个轴：【类型】【种类】【恩宠/套装】【武士/忍者】，
    四个轴互相收窄（选了任意一个，其余三个只列出还有记录的取值），规则同上。
  * 【清除筛选】恢复全部。
  * 槽位下拉框里直接打字就是搜索：多个关键词用空格分隔表示「都要命中」；
    只输入一个 16 进制/十进制 id（如 0x646b 或 25707）时，唯一命中会直接选中。
  * 武器 / 防具页签的候选词条按**这件装备自己**的词条表给：远程武器（弓 / 火枪 /
    大炮）只看远程词条表，其余武器只看近战词条表，防具看防具词条表；并且只列出
    源表标着「装备种类」相容的词条——例如只标「近战」的词条不会出现在弓的列表里。


四、写入前必须知道的几件事
------------------------------------------------------------------------
  * 程序只改副本。原档从头到尾不会被写入，写入前还会再校验一次原始哈希。
  * 词条改写时会同时改写该词条的「种类」（游戏里词条前面的那个小图标），
    所以游戏里看到的图标会跟着新词条变，不会停在旧词条上。
  * 屏幕上显示的等级/数值只是存档里的数字；改完请进游戏确认一遍再继续用。
  * 关卡中途、任务中途的存档不要改，读档可能回退；改前请留好备份。


五、合法规则（程序会强制检查）
------------------------------------------------------------------------
 1) 同一个物品每个「种类」只能有一个词条。例外：
      * 「其他」这个种类可以有多个；
      * 同种类的「一个 ★（星号）」与「一个同名固定」可以并存，不能有第三个。
    一个物品可以有多个 ★ 词条，只要它们种类各不相同。
 2) 一个物品只能有一个恩宠/套装。恩宠/套装只能**替换**存档里本来就有的那一个槽，
 不凭空新增：记录里没有恩宠/套装槽时程序会带原因拒绝。
     **恩宠和套装不能互换**：套装与物品种类强绑定（例如「加贺百万石的荣华」只出在
     百万石之铠与百万石长枪上），所以**套装槽一旦存在就锁死**，既不能换成别的套装，
     也不能改成恩宠；**恩宠槽只能换成另一个恩宠**。
 3) 固定词条（包括存档里带「固定」属性的、词条表里没收录的）不能改，也不能新增。
    武器 / 防具上的同名固定词条同样只显示、不能手写，它由「改种类」自动带入。
 4) 词条必须来自随包的合法词条表；表里没有的 id 一律拒绝写入。
    武器 / 防具还要求这条词条的「装备种类」标签与这件装备相交，否则拒绝。
 5) 只拦「这次改动新造出来的」问题：存档里本来就异常的记录，不会被无关的改动卡住。
 被拒绝时界面会说明是哪一条记录、哪几个槽、违反哪条规则。
 6) 换恩宠/套装时只改这一槽的词条 id 与数值（值只取名表自己的目录值）；槽里的其它
 标识——种类码（0x0C00，「其他」）、固定位、★ 位、第 11 字节——原样保留。
 恩宠/套装槽从来不算固定词条，固定位不影响它；名表之外的 id 一律拒绝。
     恩宠/套装所在的**那一条词条槽**里只会列出恩宠族的条目（恩宠 10 条 +
     上位恩宠 11 条），你选不到套装 —— 也就不会误改。
     槽位说明会直接标出来：套装显示「（不可替换）」并写明套装与物品种类强绑定；
     恩宠显示「（恩宠 / 上位恩宠）」并提示「在这一槽里换成另一个恩宠」；
     它们都不会被说成「固定词条」。
 换完之后游戏能正常识别（已进游戏实测确认）；仍然建议先在副本上试、留着自动备份。


六、常见问题
------------------------------------------------------------------------
 Q: 双击后什么都没发生 / 弹了一下就没了？
 A: 看同目录有没有日志或错误提示；也可以在命令行里运行
    Nioh3EquipmentAffixEditor.exe version 查看程序是否能正常输出（这条命令只打印版本）。

 Q: 提示「游戏正在运行，已拒绝写入」。
 A: 关掉游戏再试。这是防止边玩边写导致存档被覆盖。

 Q: 某个槽是灰的，选不了。
 A: 它可能是固定词条、空槽位（当前周目不能改），或套装槽（套装不可替换）。
    槽位说明行会写出原因。

 Q: 想改的词条在列表里找不到。
 A: 该词条不在随包的合法词条表里（或它的「装备种类」标签与这件装备不相容），
    程序不会凭空写；可以改用同类词条，或反馈词条名。

 Q: 改完游戏里数值没变？
 A: 先看底部【仅演练（不写入）】有没有被勾着 —— **勾着它写入不会生效**（按钮区会有红字提示，
    写入确认框顶部也会再写一次）。确认没勾选后，再确认你进游戏读的是点【写入存档】写出的
    那个副本文件，而不是原档；也确认改动前的预览里有这一条（没勾选的改动不会被写入）。

 Q: 武器 / 防具上的恩宠 / 套装怎么换？
 A: 恩宠就在它的**词条槽**里换：选中记录后，找到标着「在这一槽里换成另一个恩宠」的
    那一条槽，下拉里只会列出恩宠族的条目（恩宠 10 条 + 上位恩宠 11 条），选好之后
    点【应用修改】并确认。
    只替换这条记录**已有**的那一个恩宠/套装槽，不会凭空新增；一件装备只能有一个。
    套装槽会置灰并写明「不可替换」（套装与物品种类强绑定，任何替换都会被拒绝），
    恩宠槽也不能清空。
    写入只改这一槽的词条 id 与数值（值只取名表自己的目录值），槽里的种类码
    （0x0C00，「其他」）、固定位、★ 位、第 11 字节都原样保留——恩宠/套装槽不算
    固定词条，固定位不影响它；名表之外的 id 一律拒绝。
    命令行的 edit --grace 只对饰品有效，武器 / 防具请用界面。
    注意：换完之后游戏能正常识别（已实测确认），但仍建议先在副本上试、留着自动备份。


七、武器 / 防具页签怎么用
------------------------------------------------------------------------
 1) 和饰品一样：先【读取数据】，再切到【武器】或【防具】页签。两个页签用的是同一份
    已解密数据，不需要再读一次存档。
 2) 左侧列表显示：记录号 + 种类名、类型（小类）、恩宠/套装、等级、+值、品质。
    用四个筛选轴（【类型】【种类】【恩宠/套装】【武士/忍者】）收窄，【清除筛选】恢复。
 3) 右侧就是这件装备的词条槽：
      * 可改的槽：下拉选择或在框里打字搜索（候选只来自这件装备的词条表）；
      * 标着「固定，不可修改」的槽是这件装备固有的同名固定词条，改不了；
      * 标着「在这一槽里换成另一个恩宠」的槽是恩宠词条：**就在这一槽里换**，
        下拉只列恩宠族（恩宠 + 上位恩宠）；套装槽会置灰并写明「不可替换」；
      * 置灰的空槽是**当前周目不能改**的空槽位；
      * 槽位说明行会写出原值、标识与可改区间。
     换恩宠/套装时只替换这条记录本来就有的那一个槽（不凭空新增），写入只改这一槽的
     词条 id 与数值；怎么换、有哪些限制见第六节的常见问题。
 4) 等级上限 180，+值上限按大类（武器 / 防具都是 0..30）；稀有度上限 4（魂核 3）。
 改完**不用逐个确认**：点一次【应用修改】，它会把 词条 / 等级 / +值 / 稀有度 /
 恩宠 里的改动一起算出来，弹一次确认后应用。
 5) 点了【预览改动】只会显示「哪些槽会从什么变成什么」，不会写任何数据。
 6) 【新建到空槽】是**实验性**功能（需要进游戏实测确认）：它在页面**最下方的独立框**里，
   和上面的词条 / 等级 / +值 / 稀有度编辑区隔开；武器 / 防具的框里也可以填稀有度
   （留空就沿用模板）。选好种类、等级、+值再点按钮，
    程序会先告诉你用哪条记录当模板（优先同种类，没有同种类时改用同类型并说明原因、
    列出被清空的槽），确认后才写进内存。找不到同种类样本时会以同类型样本为模板并清掉
    不适用词条，此路径尚未经游戏实测。
 7) 全部改完点【应用修改】（本页【预览改动】旁边那个，或窗口底部那条——底部按钮按
    当前页签生效，在武器 / 防具页签点它不会去动饰品页签的选中项），再点【写入存档】
    ——写入流程与饰品页签完全一样：只写你指定的副本、写入前自动备份。

  8) 稀有度（品质）也可以改：用右侧的【稀有度】输入框填新数值（上限按大类，橙色 5 在当前周目不可达），
     和其他改动一起由【应用修改】写入；写入只改品质字段（+0x30 的低 4 位），
     词条、等级、+值、标识都不动。

 注意：无中生有造出来的新装备还没有在实机存档里核对过；恩宠替换**已实测确认**
 （游戏能正常识别）。用之前仍然建议先备份，进游戏确认图标与词条都对得上再继续。


八、改稀有度（品质）
------------------------------------------------------------------------
 1) 四个页签（饰品 / 魂核 / 武器 / 防具）都在「等级」「+值」旁边多了一行【稀有度】。
 2) 用法：先在左侧选中一条记录（框里会显示它当前的稀有度），填上新数值，
    和其他改动一起由【应用修改】写入。和改等级 / +值 完全一样：改动先进内存，界面会提示
    「（内存中，尚未写入存档）」，最后统一点【写入存档】才落到副本上。
 3) 写入只动品质字段（+0x30 的低 4 位）；写成 0 时会顺带清掉 +0x31 的低 4 位
    （否则程序读回时会退回旧值）。词条、等级、+值、标识一个都不动。
 4) 上限按**这条记录所属的大类**取（查的是随包的 data\equipment_items.json）：
     武器 / 防具 / 饰品  0..4（神器）
     魂核                0..3（特大名器，比其它大类低一档）
    记录的种类不在那份总目录里时程序会直接拒绝（无法确定上限，宁可不写）。
 5) 稀有度对应的游戏内颜色：0 白色、1 黄色、2 蓝色、3 紫色、4 绿色、5 橙色。
    颜色只用于显示，**不是**上限。橙色（5）在当前周目（三周目：本体 + DLC1）
    不可达，等 DLC2 / 四周目开放后才可能开放 —— 那时也只需改程序里 limits.py
    的一张表（等级上限 180 与 +值上限同样出自它，见第五节）。
 6) 越界（例如武器写 5、魂核写 4）或表外种类会被拒绝，对话框里会写清是哪一类、
    上限几、以及上限的来历。切换记录时这一行会跟着刷新（值和范围都是新记录的），
    没选记录时整行置灰。


九、随程序附带的文件
------------------------------------------------------------------------
  data\accessory_affixes.json   饰品合法词条表（可自行查看）
  data\soul_affixes.json        魂核合法词条表
  data\grace_affixes.json       恩宠/套装名表（给饰品与武器 / 防具的恩宠/套装槽
                                命名与校验；武器 / 防具的下拉也从它取值）
  data\accessory_items.json     饰品种类表    data\soul_items.json  魂核种类表
  data\melee_weapon_affixes.json   近战武器合法词条表（含「装备种类」标签）
