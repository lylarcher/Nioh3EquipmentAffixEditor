========================================================================
 仁王 3 饰品 / 魂核 存档修改器 —— 使用说明（给使用者看）
========================================================================

 仅供测试学习用，不要用于联机影响游戏平衡。
 请先备份存档再使用；本程序只写你指定的副本，绝不改原档。

 开发者请看 README.md / README.zh-CN.md；本文件只讲怎么用。
------------------------------------------------------------------------


一、这是什么
------------------------------------------------------------------------
一个单文件 Windows 程序，用来查看和修改存档里的饰品与魂核：

  * 饰品页签：看/改饰品记录的词条、等级、+値、品级、种类、恩宠/套装
  * 魂核页签：看/改魂核记录的词条、等级、+値
  * 每个词条槽都能下拉选择或直接搜索词条（空格分隔多个关键词 = 同时满足）
  * 程序会拦下不合法的改法（详见第五节的合法规则）

运行要求：Windows 10/11 64 位。首次运行会在自己所在目录旁解压出数据文件
（词条表、图标、加解密组件），属于正常现象；只删除 exe 不会删掉这些文件，
要清干净请把整个文件夹一起删掉。


二、第一次打开：按这个顺序操作
------------------------------------------------------------------------
 1) 关掉游戏。游戏在运行时程序会拒绝写入，这是故意的。

 2) 备份原存档。
    存档一般在：  文档\KoeiTecmo\NIOH3\Savedata\<你的账号ID>\SAVEDATA00\
    里面有 SAVEDATA.BIN 等文件。把整个 SAVEDATA00 文件夹复制一份留底。

 3) 双击 Nioh3AccessoryEditor.exe 打开界面（没有命令行黑框）。

 4) 点【浏览…】选中原存档里的 SAVEDATA.BIN。
    选中后程序会显示它的路径与大小；界面下方那一行会告诉你当前用的是哪个文件。

 5) 点【读取数据】。
    读完后左侧出现记录列表，右侧是选中记录的词条槽；状态栏会显示记录条数。
    读不出来（提示找不到记录表）说明存档结构没被识别，先别改，把情况反馈过来。

 6) 在左侧列表里点一条记录。右侧 7 个词条槽会填上当前内容：
      槽位下拉框   这个词条是什么（可下拉选择/打字搜索）
      数值输入框   这个词条的数值（固定取值的词条会置灰，不能填）
      槽位说明行   显示存档里的原值、标识、以及为什么不能改（如固定词条、恩宠槽）

 7) 要改哪一项就改哪一项：
      * 换词条：在对应槽的下拉框里选一个新词条；也可以在框里输入关键词搜索，
        回车或选中等候列表刷新；清空输入会恢复该槽的完整词条表。
      * 改数值：在数值框里填数字（有范围的词条会提示范围）。
      * 改等级 / +値：用界面上的等级、+値输入框与按钮（等级上限 180，+値上限 30）。
      * 换恩宠/套装：用【恩宠】栏选择，不要在词条槽里改恩宠。
      * 固定词条（含存档里标了「固定」的）一律不能改，槽位会置灰。
      * 需要新记录时用【无中生有】/【创建】按钮，按你选的同类物品造一条新记录。

 8) 检查右侧的预览列表：它列出本次将要写入的每一条改动（记录号、槽位、旧→新）。
    不想写这一条就在左侧取消勾选这一条改动。

 9) 点【应用修改】。
    程序会把改动写进内存并逐条校验；有不合法的改法会当场拒绝并说明原因（例如同一
    个物品里出现了两个同种类的词条）。

10) 点【写入副本】把结果保存成新文件。
    程序只写你指定的副本路径（默认写到一个单独的测试目录），不会覆盖你选中的原档。

11) 进游戏读取那个副本（放在存档目录里），确认改动生效、图标与文字都对得上。


三、筛选与查找
------------------------------------------------------------------------
  * 顶部筛选行：按【种类】【恩宠/套装】筛记录；两个筛选会互相收敛——只列出另一个
    筛选仍然允许的选项；当前选择若已无记录，会显示成「xxx（当前无记录）」而不是被
    悄悄清掉，避免你以为筛选没生效。
  * 【清除筛选】恢复全部。
  * 槽位下拉框里直接打字就是搜索：多个关键词用空格分隔表示「都要命中」；
    只输入一个 16 进制/十进制 id（如 0x646b 或 25707）时，唯一命中会直接选中。


四、写入前必须知道的几件事
------------------------------------------------------------------------
  * 程序只改副本。原档从头到尾不会被写入，写入前还会再校验一次原始哈希。
  * 词条改写时会同时改写该词条的「种类」（游戏里词条前面的那个小图标），
    所以游戏里看到的图标会跟着新词条变，不会停在旧词条上。
  * 屏幕上显示的等级/数值只是存档里的数字；改完请进游戏确认一遍再继续用。
  * 关卡中途、任务中途的存档不要改，读档可能回退；改前请留好备份。


五、合法规则（程序会强制检查）
------------------------------------------------------------------------
 1) 同一个物品每个「种类」只能有一个词条。例外：
      * 「其他」这个种类可以有多个；
      * 同种类的「一个 ★（星号）」与「一个同名固定」可以并存，不能有第三个。
    一个物品可以有多个 ★ 词条，只要它们种类各不相同。
 2) 一个物品只能有一个恩宠/套装。
 3) 固定词条（包括存档里带「固定」属性的、词条表里没收录的）不能改，也不能新增。
 4) 词条必须来自随包的合法词条表；表里没有的 id 一律拒绝写入。
 5) 只拦「这次改动新造出来的」问题：存档里本来就异常的记录，不会被无关的改动卡住。
 被拒绝时界面会说明是哪一条记录、哪几个槽、违反哪条规则。


六、常见问题
------------------------------------------------------------------------
 Q: 双击后什么都没发生 / 弹了一下就没了？
 A: 看同目录有没有日志或错误提示；也可以在命令行里运行
    Nioh3AccessoryEditor.exe version 查看程序是否能正常输出（这条命令只打印版本）。

 Q: 提示「游戏正在运行，已拒绝写入」。
 A: 关掉游戏再试。这是防止边玩边写导致存档被覆盖。

 Q: 某个槽是灰的，选不了。
 A: 它可能是固定词条，或恩宠/套装槽（后者用【恩宠】栏改）。槽位说明行会写出原因。

 Q: 想改的词条在列表里找不到。
 A: 该词条不在随包的合法词条表里，程序不会凭空写；可以改用同类词条，或反馈词条名。

 Q: 改完游戏里数值没变？
 A: 确认你进游戏读的是「写入副本」那个文件，而不是原档；也确认改动前的预览里有
    这一条（没勾选的改动不会被写入）。


七、随程序附带的文件
------------------------------------------------------------------------
  data\accessory_affixes.json   饰品合法词条表（可自行查看）
  data\soul_affixes.json        魂核合法词条表
  data\grace_affixes.json       恩宠/套装名表（只用于显示槽位名称）
  data\accessory_items.json     饰品种类表    data\soul_items.json  魂核种类表
  config\editor.json            参数配置（改完重启生效）
  assets\*, bin\*               图标与随附的加解密组件
  third_party\source-data\*     原始数据表（供重新生成词条表）
  CHANGELOG.md                  每个版本的改动
